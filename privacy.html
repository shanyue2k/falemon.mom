隐私保护政策 (Privacy Policy)

快柠檬将用户隐私安全置于首位，坚决奉行零日志承诺

1. 严正承诺：绝不保留用户使用日志 (No-Logs Guarantee)

🔒 核心原则：快柠檬 Falemon 秉持并践行严格的“零使用日志（Zero-Logs Policy）”。我们既不监控、不记录、不追踪，也绝不存储任何用户的网络浏览行为与通讯内容。

我们明确承诺绝对不收集、不记录以下任何数据：

  • 无访问日志：绝不记录您浏览过哪些网站、打开过哪些应用程序或下载过哪些具体文件；
  • 无流量内容日志：所有传输数据经现代工业级加密算法全程封装传输，绝不解密、抓包或窥探通信数据包正文；
  • 无真实 IP 关联记录：绝不记录您连接快柠檬专线时本地分配的公网真实 IP 地址；
  • 无 DNS 查询日志：所有域名的解析均由快柠檬在专线内存节点中自建的无污染纯净递归 DNS 完成，解析记录随查随焚，不作任何长期持久化存储；
  • 无连接会话时间戳：绝不存储用户何时连入、何时断开节点的具体精确时间关联表。

2. 我们仅收集的最小化服务数据

为了保障账号的基本可用性及套餐订阅的正常流转，我们仅收集并加密存储以下维持服务所必需的最简技术数据：

  • 账号凭证：用于注册登录的用户邮箱地址（支持匿名邮箱）及经由强哈希算法（Bcrypt / Argon2）加盐单向加密的用户密码。
  • 套餐与流量计量：当前套餐的到期时间、剩余总流量及已使用流量总计（仅为总字节数值，绝不包含任何流量来源或内容属性）。
  • 并发设备数限制统计：当前正在连入该账号节点的活跃连接数量（仅为内存计数器，用于防止滥用转售，连接终止即从内存清零）。

3. 纯内存架构与安全隔离

快柠檬核心转发集群全部采用只读内存系统（RAM-Disk / tmpfs）架构，服务器物理硬盘不挂载任何系统运行日志分区。一旦服务器重启或遭遇非正常断电，内存中的瞬时易失性缓存数据将即刻彻底消失，从物理原理上彻底断绝任何日志泄露的可能性。

4. 零出售与绝不向第三方披露

快柠檬 Falemon 不参与任何广告画像商业化联盟，绝不会以盈利、置换等任何目的向第三方广告商、数据经纪公司出售、出租或分享任何用户信息。因为我们根本不记录您的活动日志，所以即使面对任何外部机构的索求，我们也“无数据可供提供”。

5. 政策更新与联系我们

我们可能会适时修订本隐私政策以适应新的技术标准或合规要求。建议您定期查阅。若您对快柠檬的隐私保护机制有任何疑问或改进建议，可通过用户中心提交专属客服工单联系我们。
